# Financial LSTM Training Project

## 项目简介
本项目用于基于财务文本（如MDA）和财务指标，利用FinBERT和LSTM模型进行特征提取与预测建模。项目结构清晰，参数集中管理，便于扩展和维护。

## 目录结构
```
├── config.py            # 配置文件，集中管理参数
├── data_loader.py       # 数据加载与预处理
├── embedding.py         # 文本嵌入生成（FinBERT）
├── model_lstm.py        # LSTM模型定义
├── train.py             # 训练主流程
├── requirements.txt     # 依赖包列表
├── README.md            # 项目说明
```

## 依赖安装
建议使用Python 3.8+。

请先安装依赖：
```bash
pip install -r requirements.txt
```

## 数据准备
请将标准化后的数据文件命名为 `normalized_data.csv`，放在项目根目录下。数据需包含如下字段：
- Stkcd（公司代码）
- Accper（会计期间/年份）
- ManaDiscAnal（MDA文本）
- 以及各类财务指标

## 运行方法
直接运行训练脚本：

```bash
python train.py
```

所有参数均可在 `config.py` 中修改，包括模型结构、训练轮数、批量大小、文件名等。

## 项目原理与流程

### 1. 数据流与整体流程
1. **数据加载**：读取标准化后的财务数据（CSV），每家公司每年一条记录。
2. **文本嵌入**：对每条MDA文本，使用FinBERT模型提取语义特征（向量）。
3. **特征拼接**：将文本特征与对应的财务指标拼接，形成每条样本的完整特征。
4. **数据组织**：将所有公司数据整理为三维张量（公司数 × 年份数 × 特征数）。
5. **模型训练**：用LSTM模型对拼接后的特征序列进行建模，预测目标变量。

### 2. 关键技术模块
#### （1）FinBERT文本嵌入
- 输入：一段MDA文本。
- 输出：一个768维的向量，代表该文本的语义特征。
- 作用：将原始文本转为模型可处理的数值特征。

#### （2）财务指标特征
- 从原始数据中剔除无关字段（如公司代码、年份、原始文本等），剩下的数值型财务指标作为特征。

#### （3）特征拼接
- 对每条样本，将FinBERT输出的文本向量与财务指标向量拼接，形成最终输入特征。

#### （4）LSTM模型
- LSTM（长短期记忆网络）是一种适合处理序列数据的神经网络。
- 输入：每家公司按年份排序的特征序列。
- 输出：对目标变量的预测（如未来某财务指标）。
- 优点：能捕捉公司财务和文本信息随时间变化的动态特征。

#### （5）训练流程
- 所有公司数据组成批次，输入LSTM模型。
- 损失函数采用均方误差（MSELoss），优化器为Adam。
- 训练过程中不断调整模型参数，使预测结果更接近真实值。

```
train.py
  └─> prepare_data() [data_loader.py]
        └─> get_finbert_embeddings() [embedding.py]
  └─> FinancialDataset [data_loader.py]
  └─> LSTMModel [model_lstm.py]
  └─> 训练与评估
```
