# 多风险融合预测
选取财务困境风险和内部控制风险进行融合实验，原因有以下两点：
- 风险典型性：财务困境是上市公司的外显风险，通常可以通过财务指标等硬数据分析得出；而内部控制风险属于上市公司的内隐风险，则需要通过年报文本等软数据分析得出，两者的结合充分体现了我们的核心思想：利用多模态数据融合多风险，相互补充，更好地表示公司整体风险
- 数据可得性：这2个风险的数据量充足，不像信用风险由于信用评级非强制要求，每年的缺失值较多，对齐操作后所剩数据过少，不能有效支撑实验的进行
## 实验方法
- 将Train_text文件夹压缩后打包上传至openbayes云计算平台后解压，分别以input_st.data和input_inner.data为源数据运行train.py，得到财务困境和内部控制两个风险的最后一个隐藏层的表示向量
- 运行integrating.ipynb，将两个风险对齐拼接得到整体向量，并进行全连接层的降维操作后分别用两个不同的输出层对财务困境和内部控制风险做出预测
